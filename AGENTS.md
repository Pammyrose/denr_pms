# Project instructions

For coding tasks in this repository, use the [pms-specs-first skill](.agents/skills/pms-specs-first/SKILL.md).

Before editing application code, tests, migrations, or configuration, read the existing Markdown specifications in `specs/` as directed by the skill. Verify relevant behavior against the implementation and keep affected specifications aligned with intentional behavior changes.

The user's current request takes precedence over older specifications. Resolve routine implementation decisions without introducing additional approval steps.
